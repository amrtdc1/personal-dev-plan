# Phase 0 Baseline

## Goals
- Preserve behavior from legacy app before enhancement work.
- Establish release gates for security, responsiveness, and offline reliability.

## Explicit Deferrals During Parity
- New visual theme expansions (including college athletics branding) are deferred until parity gates are passing.
- Enhancement work can proceed in parallel only when it does not delay security, authorization, offline, and calendar parity milestones.

## Acceptance Gates
- Security: no unsafe HTML rendering of user content.
- Authorization: server-side ownership enforcement for all user data routes.
- UX: desktop, iPad, and mobile critical flows complete.
- Offline: installable PWA + queued offline writes with reconnect replay.
- Calendar: ICS export and subscription compatibility checks.

## Legacy Surface To Parity-Map
- Goals / Sub-goals / Tasks CRUD
- Status rollups and dashboard stats
- Calendar timeline + due date markers
- Journal entries and filtering
- Theme + palette preferences
- Account management flows
